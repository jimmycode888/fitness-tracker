# CYBERFIT · 赛博运动打卡终端

纯静态的运动 / 饮食 / 体成分记录应用。**单文件、零依赖、离线可用**——`index.html` 内已内联全部 CSS、JavaScript 与 Chart.js，直接双击即可在浏览器中运行，不需要任何服务器或网络。

## 功能

**六个页面**（hash 路由，支持键盘 `1`–`6` 快捷切换）

| 页面 | 内容 |
| --- | --- |
| 首页 | 今日目标进度环、连续打卡、周目标、12 周活跃热力图、今日热量收支 |
| 饮食摄入 | 内置 65 种食物库、份量计算、自定义食物、三餐分组、营养素构成 |
| 运动打卡 | 8 种运动类型、时长 / 距离 / 强度、按 MET 估算卡路里、配速 |
| 身体指标 | 三种体脂率公式、BMI / LBM / BMR / TDEE / 腰高比 / 理想体重 |
| 数据看板 | 8 张 Chart.js 图表，覆盖运动、热量收支、营养素与体成分趋势 |
| 历史记录 | 按项目 / 时间 / 时长 / 卡路里筛选与搜索 |

## 体脂率计算公式

- **围度法（美国海军法）** — 由身高、腰围、颈围（女性加臀围）推算，误差约 ±3%
- **BMI 法（Deurenberg）** — `1.20×BMI + 0.23×年龄 − 10.8×性别 − 5.4`
- **皮褶法（Jackson-Pollock 3 点）** — 先算体密度再用 Siri 公式换算，误差约 ±2%

## 热量收支模型

```
每日消耗 = BMR × 1.2（基础日常） + 运动打卡消耗
热量缺口 = 每日消耗 − 饮食摄入
```

BMR 采用 Mifflin-St Jeor 公式；TDEE（BMR × 活动系数）作为独立参考值展示，避免与运动消耗重复计算。

## 数据存储

全部数据保存在浏览器 `localStorage`，不上传任何服务器：

| Key | 内容 |
| --- | --- |
| `cyberfit.records.v2` | 运动打卡记录 |
| `cyberfit.diet.v1` | 饮食记录 |
| `cyberfit.body.v1` | 身体数据记录 |
| `cyberfit.settings.v2` | 目标、体重与身体围度设置 |

支持导出 CSV（Excel 可直接打开）与 JSON 备份 / 恢复。若浏览器禁用了本地存储，会自动降级为内存模式并提示。

## 其他

- 赛博朋克霓虹风格：canvas 粒子背景（鼠标交互）、透视网格地面、扫描线叠加、CSS 入场动画
- 响应式：PC 端侧边栏（≥900px）/ 移动端底部 6 项 Tab 栏（≤900px）
- 遵循 `prefers-reduced-motion`，关闭动画偏好时自动降级
- 首次使用可点击「生成示例数据」快速体验全部图表

## 本地运行

```bash
# 方式一：直接双击 index.html

# 方式二：起个本地服务（推荐，localStorage 行为更稳定）
python -m http.server 8000
# 然后访问 http://localhost:8000
```
